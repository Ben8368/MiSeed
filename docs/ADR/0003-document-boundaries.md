# ADR 0003：双入口与文档职责互斥

- 状态：已接受
- 日期：2026-11-05

## 背景

用户要求 AGENTS 服务 AI、README 服务人类开发者，docs 按需读取且简短。原文档多处重复导航、状态、验证与安全规则，增大加载成本。

## 决策

- 文档正文按职责唯一归属；职责表与篇幅预算集中在 GOVERNANCE，允许必要的一句摘要和链接。
- AI 先读短状态/经验索引，再按任务定位章节；链接不触发递归读取，历史只按追溯需要加载。
- 删除重复 docs/README；通用维护者职责并入治理/审查规范；背景与来源调研移入 archive。
- 收紧入口预算并覆盖其他活动文档；超限先精简/归档，不机械拆篇或提高上限。

## 后果

当前事实、规则、实施顺序与历史依据分离；减少文档与默认上下文。预算可自动检查，语义职责互斥仍须人工审查。补充 ADR-0001 的文档治理细则，不改变设备安全、授权或证据门禁。
