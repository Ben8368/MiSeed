# ADR 0005：项目自有内容采用 AGPL-3.0-only

- 状态：已接受
- 日期：2026-11-05

## 背景

维护者要求采用强 copyleft 开源许可。MiSeed 同时涉及 Linux 内核派生代码、UEFI、Recovery 和第三方固件/工具，不能用一个根许可证覆盖所有依赖。

## 决策

MiSeed 原创内容在未单独标注其他许可证时采用 AGPL-3.0-only，文本见根目录 `LICENSE`。AGPLv3 要求分发对应源代码，并在适用的用户产品分发中提供安装信息；支持远程网络交互的修改版本还须向交互用户提供源码获取方式。AGPLv3 含贡献者专利授权及专利诉讼终止条款。选择 AGPL 而非 GPL，是为了保留网络服务场景中的源码共享义务；固定 v3-only，不自动允许按后续版本分发。

Linux GPL-2.0-only 派生文件继续使用 GPL-2.0-only，逐文件 SPDX 标识；AGPLv3 与 GPLv2-only 不兼容，禁止将二者合并成单一衍生作品。EDK II/Mu、DTS、Recovery 包和固件保留各自来源许可，逐文件/组件登记；BSD 类代码可作为其独立许可组件，不能删除归属或误标为 MiSeed 原创。

## 后果

原创代码允许商业使用和再分发，但分发衍生作品须履行 AGPLv3 对应源代码、许可证文本、修改声明及适用安装信息义务；若支持远程网络交互，还须按 §13 向远程用户提供源码。发布设备镜像前须做逐文件许可清单和 AGPLv3 §6/§13 审查。该决定不授权引入未审来源，也不改变现存第三方许可证。
